# ritual. — персональный уход за кожей

**Версия 1.1** — персональный календарь уходовых процедур и дневник кожи.

### Возможности
- Режимы календаря: день, неделя, месяц и год.
- 12-недельный план с осторожным введением Скинорена 15% без автоматического увеличения частоты.
- Ежедневный дневник состояния кожи с графиками и оценкой раздражения.
- Карточки средств с инструкциями и фотографиями упаковок (фото с внешних сайтов могут быть недоступны).
- Режим минимального ухода и статус косметики.
- Светлая и тёмная темы, адаптация для iPhone и десктопа.
- Офлайн-режим для интерфейса после первой загрузки.

## Сайт
**https://eldaroos.github.io/ritual-skincare/**

Если GitHub Pages ещё не включён: **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**.

После обновления сайта на iPhone может потребоваться перезагрузка страницы, чтобы обновился офлайн-кэш.

## Установка на iPhone
Открой HTTPS-адрес в Safari → «Поделиться» → «На экран Домой».

## Данные и конфиденциальность
Прогресс, журнал, настройки и статусы косметики хранятся в `localStorage` для **конкретного адреса сайта**. Между Mac и iPhone они не синхронизируются. Обновление 1.1 читает сохранения прежней версии (`ritual-skincare-v1`) при первом запуске и сохраняет новые изменения под ключом `ritual-skincare-v11`.

Сохраняй резервную копию через экспорт в настройках. При очистке данных сайта информация может исчезнуть. Изображения товаров загружаются с внешних сайтов и могут передавать этим сайтам обычные технические сведения запроса, но дневник и прогресс приложением никуда не отправляются.

## Важно
Приложение — помощник, а не медицинское назначение. Если появились болезненные воспаления, рубцы, стойкая сухость или раздражение, стоит обратиться к дерматологу.
