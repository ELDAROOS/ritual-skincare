# ritual. — персональный помощник по уходу за кожей

Сайт-календарь с дневным, недельным, месячным и годовым режимами, карточками средств, трекером процедур и 12-недельным планом осторожного введения Скинорена 15%.

## Сайт на GitHub Pages

Адрес после включения GitHub Pages: https://eldaroos.github.io/ritual-skincare/

Включить: **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**.

Сайт не требует сборки, сервера или API-ключей. Файлы `index.html`, `icon.svg`, `manifest.webmanifest` и `sw.js` должны находиться в корне.

## Установка на iPhone

Открой опубликованный HTTPS-адрес в Safari → «Поделиться» → «На экран Домой».

## Данные и приватность

Отметки ухода, дата старта и подтверждения этапов сохраняются только в `localStorage` браузера для данного адреса. Они **не синхронизируются** между iPhone и Mac. При очистке данных сайта могут исчезнуть. Для переноса используй экспорт и импорт резервной копии в настройках сайта. Данные, сохранённые при открытии локального HTML-файла, автоматически не перенесутся на GitHub Pages — сначала экспортируй их.

## Медицинская оговорка

План является информационным помощником, а не назначением врача. Наращивание частоты Скинорена не происходит автоматически; требуется подтверждение переносимости. При болезненных узлах, рубцах или стойком раздражении обратись к дерматологу.
